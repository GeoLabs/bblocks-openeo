This Building Block proposes a schema representation of the OpenEO process [`cosh`](https://processes.openeo.org/#cosh) — *Hyperbolic cosine*. It models the `arguments` object of a process graph node invoking `cosh`. This is a proposed correspondence between the OpenEO process definition and an OGC Building Block schema, not a settled equivalence.

Computes the hyperbolic cosine of `x`.

No-data values are passed through.
